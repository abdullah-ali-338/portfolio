# 🌐 Minimalist Developer Portfolio — Muhammad Abdullah Ali

A clean, responsive, single-file personal portfolio engineered with a technical specification and print-editorial aesthetic. Designed to highlight backend architectures, systems engineering projects, and API infrastructure.

**Live Site:** https://abdullah-ali-338.github.io/portfolio

---

## 📐 Design Architecture

- **Aesthetic:** Editorial print spec / technical catalog layout with registration marks, razor-thin hairlines, and typographic hierarchies
- **Layout:** Grid-aligned sections with zero layout shifts and mobile-first responsiveness
- **Palette:** Deep void (#111111), off-white typography (#E8E8E8), and high-contrast inverted closing panel
- **Typography:** Helvetica Neue for structural headlines paired with JetBrains Mono for metadata and system tags

---

## 🛠 Tech Stack

- **Markup & Structure:** HTML5 (Semantic Structure)
- **Styling:** Tailwind CSS (CDN) + Custom Embedded CSS
- **Typography & Assets:** Google Fonts (Helvetica Neue, JetBrains Mono)

---

## 📂 Repository Structure

```
├── index.html          # Core single-file portfolio source
└── README.md           # Project documentation and setup guide
```

## 🚀 Local Setup & Deployment

**1. Clone the repository:**

```bash
git clone https://github.com/abdullah-ali-338/<repo-name>.git
cd <repo-name>
```

**2. Run locally:**

Open `index.html` directly in your browser, or serve via a local dev server:

```bash
# Python 3
python -m http.server 8000
```

**3. Deploy:**

Host using GitHub Pages, Render, or Vercel by pointing the root directory to `index.html`.
