A clean, responsive, single-file personal portfolio engineered with a technical specification and print-editorial aesthetic. Designed to highlight backend architectures, systems engineering projects, and API infrastructure.

🌐 **Live Demo:** [abdullah-ali-338.github.io/portfolio](https://abdullah-ali-338.github.io/portfolio)

---

## ✨ Features

- **Technical Print Aesthetic:** Designed like a technical catalog with registration marks, razor-thin hairlines, and strict typographic hierarchy.
- **Zero-Shift Grid Layout:** Grid-aligned sections crafted for high readability and seamless mobile-to-desktop responsiveness.
- **High-Contrast Palette:** Minimalist color scheme featuring deep void backgrounds (`#111111`), crisp off-white text (`#E8E8E8`), and an inverted closing panel.
- **Engineered Typography:** Helvetica Neue for structural headlines paired with JetBrains Mono for system tags and technical metadata.
- **Single-File Setup:** Consolidated structure using semantic HTML and Tailwind CSS requiring zero build steps or complex dependencies.

---

## 🛠️ Tech Stack

- **Markup & Structure:** Semantic HTML5
- **Styling:** Tailwind CSS + Custom Embedded CSS
- **Typography & Assets:** Google Fonts (Helvetica Neue, JetBrains Mono)
- **Deployment & Hosting:** GitHub Pages
